# WindowsToolsコマンド一覧

WindowsToolsはウィンドウ操作・消灯・ロック・プロセス操作など固定22件を提供します。

Windows標準キーはAppDock本体のconfigs/command-sets/windows.jsonへ移りました。コマンドセンターの「コマンドセット → Windows標準キー」から割り当ててください。

このAppletの固定コマンドはmanifestで共通操作API（MCPを含む）へ公開します。実行には既存のコマンド実行許可と各操作に必要な許可を使います。

「Windowsをロックする」はキー送信を使わずWindowsへロックを要求し、無操作時の自動ロックとは独立しています。


## ターミナル・電源関連

これらはキー送信を使わず、本体のprocesses.startで呼び出します。「設定 → 操作の許可」のApplet列で、情報取得・コマンド実行・プロセス起動を許可してください。実行受付は終了操作やダイアログ表示の完了を保証しません。

| コマンド | 説明・利用条件 |
| --- | --- |
| Windowsターミナルを起動する | Windowsターミナルを起動します。Windowsターミナルのインストールとwt.exeのアプリ実行エイリアスが必要です。ウィンドウやタブの開き方はターミナルの設定に従います。 |
| Windowsをシャットダウンする | 確認ダイアログや待ち時間を設けずにWindowsのシャットダウンを要求します。強制終了の/fは指定しません。未保存の作業がある場合の確認や中止はWindowsと対象アプリに従います。 |
| Windowsを再起動する | 確認ダイアログや待ち時間を設けずにWindowsの再起動を要求します。強制終了の/fは指定しません。未保存の作業がある場合の確認や中止はWindowsと対象アプリに従います。 |
| Windowsからサインアウトする | 確認ダイアログや待ち時間を設けずに現在のユーザーのサインアウトを要求します。強制終了は指定しません。未保存の作業がある場合の確認や中止はWindowsと対象アプリに従います。 |
| Windowsのシャットダウン画面を開く | Windows標準の「Windowsのシャットダウン」ダイアログを開きます。画面で操作を選んでOKを押すまで終了操作は行わず、キャンセルできます。Alt+F4のキー送信は使いません。 |

## リモートデスクトップの最小化・復元

対象はmstsc.exeです。キートリガーでは、ScrollLockキーに割り当てて「元の入力をブロックする」を有効にしてください。

| コマンド | 説明 |
| --- | --- |
| リモートデスクトップを最小化 | リモートデスクトップ接続（mstsc.exe）の各メインウィンドウを最小化します。対象がなければ何もしません。キートリガーでは、ScrollLockキーに割り当てて「元の入力をブロックする」を有効にしてください。 |
| リモートデスクトップを最小化から復元 | リモートデスクトップ接続（mstsc.exe）の各メインウィンドウを復元し、前面化も要求します。対象がなければ何もしません。キートリガーでは、ScrollLockキーに割り当てて「元の入力をブロックする」を有効にしてください。 |
| リモートデスクトップを最小化／復元 | リモートデスクトップ接続（mstsc.exe）の各メインウィンドウについて、最小化中なら復元、それ以外なら最小化します。復元時は前面化も要求します。対象がなければ何もしません。キートリガーでは、ScrollLockキーに割り当てて「元の入力をブロックする」を有効にしてください。 |
