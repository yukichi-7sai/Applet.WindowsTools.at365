# Windows標準コマンド一覧

WindowsToolsには、Windows標準のキー操作66件と「Windowsをロックする」が組み込まれています。キー操作を個別に作成・保存しなくても利用できます。

AppDockのコマンドパレットやショートカット・ジェスチャー・トレイの割り当てから選べます。送信先は実行時の最前面です。別のアプリを操作するときはグローバルショートカットなどから実行してください。

Windowsのバージョン、機器、インストール済みアプリ、設定によって利用できる操作が異なります。コマンドを用意するだけで、必要な機能の導入や設定の変更は行いません。キー送信の完了は、Windows側の動作を確認できたという意味ではありません。

「Windowsをロックする」はキー送信を使わず、Windowsへロックを要求します。実行すると直ちにロックされ、解除にはWindowsへのサインインが必要です。無操作時の自動ロックとは独立しています。

対象は[Microsoftの一覧](https://support.microsoft.com/ja-jp/accessibility/windows/keyboard-shortcuts-in-windows)の「Windows キー キーボード ショートカット」と「複数のデスクトップのキーボード ショートカット」です。Win+Ctrl+Shift+B、Win+L、Win+カンマは含めません。Win+Tabの重複と、Win+Cの条件別の説明はまとめています。

| コマンド | キー操作 | 説明・利用条件 |
| --- | --- | --- |
| スタートメニューを開く／閉じる | `Win` | Windowsのスタートメニューを表示・非表示にします。 |
| クイック設定を開く | `Win+A` | Wi-Fi・音量などのクイック設定を開きます。表示内容はWindowsのバージョンによって異なります。 |
| 表示中のWindowsのヒントに移動する | `Win+Shift+A` | Windowsのヒントが表示されているときに、そのヒントへフォーカスを移します。表示されていなければ何も起きません。 |
| HDRをオン／オフにする | `Win+Alt+B` | HDR対応のディスプレイと利用環境が必要です。現在のHDR設定を切り替えます。 |
| CopilotまたはWindows検索を開く | `Win+C` | Copilotの導入状況とWindowsの設定に従って動作します。Copilotが利用できない場合はWindows検索を開閉します。 |
| 日付と時刻を表示／非表示にする | `Win+Alt+D` | デスクトップの日付と時刻の表示を切り替えます。 |
| ウィンドウを画面の下半分に配置する | `Win+Alt+Down` | 最前面のウィンドウを下半分にスナップします。対応するWindowsとウィンドウで利用できます。 |
| 音声入力のキーボードに移動する | `Win+Alt+H` | 音声入力が開いているときに、キーボードへフォーカスを移します。 |
| マイクをミュート／解除する | `Win+Alt+K` | この操作に対応する通話アプリなどで、マイクのミュート状態を切り替えます。 |
| ウィンドウを画面の上半分に配置する | `Win+Alt+Up` | 最前面のウィンドウを上半分にスナップします。対応するWindowsとウィンドウで利用できます。 |
| カラーフィルターをオン／オフにする | `Win+Ctrl+C` | Windowsの設定でカラーフィルターのショートカットが有効な場合に、フィルターを切り替えます。 |
| ナレーターを起動／終了する | `Win+Ctrl+Enter` | Windowsの画面読み上げを切り替えます。ナレーターのショートカットが無効な場合は動作しません。 |
| ネットワーク上のデバイスを検索する | `Win+Ctrl+F` | ネットワーク上のデバイスを探すWindowsの画面を呼び出します。ネットワーク構成によって利用できない場合があります。 |
| クイックアシストを開く | `Win+Ctrl+Q` | クイックアシストが必要です。支援用の画面を開きます。画面を開くだけで他の人との接続は始まりません。 |
| 直前に使っていた入力方式に戻す | `Win+Ctrl+Space` | 以前に選択していた入力オプションへ切り替えます。複数の入力方式がある場合に利用できます。 |
| サウンド出力の設定を開く | `Win+Ctrl+V` | 対応するWindowsで、出力デバイスや音量ミキサーなどのクイック設定を開きます。 |
| デスクトップを表示／元に戻す | `Win+D` | ウィンドウを隠してデスクトップを表示します。もう一度実行すると元の表示に戻します。 |
| ウィンドウを縮小／最小化する | `Win+Down` | 最前面のウィンドウの現在の状態に応じて、最大化を解除するか最小化します。 |
| エクスプローラーを開く | `Win+E` | Windowsのエクスプローラーを開きます。 |
| 拡大鏡を終了する | `Win+Escape` | Windowsの拡大鏡が起動している場合に終了します。 |
| フィードバックHubを開く | `Win+F` | フィードバックHubが必要です。Windowsへの意見や問題を送るための画面を開きます。 |
| IMEで文字を再変換する | `Win+Slash` | 入力中のアプリでIMEの再変換を呼び出します。対応するIMEと変換対象の文字が必要です。 |
| Game Barを開く | `Win+G` | Game Barがインストールされ、有効になっている場合に開きます。 |
| 音声入力を開く | `Win+H` | Windowsの音声入力を開きます。文字を入力できる場所と、音声入力に対応する環境が必要です。 |
| 他のウィンドウを最小化／元に戻す | `Win+Home` | 最前面のウィンドウを残して他のウィンドウを最小化します。もう一度実行すると戻します。 |
| Windowsの設定を開く | `Win+I` | Windowsの設定アプリを開きます。 |
| Recallを開く | `Win+J` | Recallの最小システム要件を満たし、機能が利用可能なPCで動作します。 |
| ワイヤレスディスプレイへの接続を開く | `Win+K` | Windowsのキャスト画面を開きます。実際の接続には対応するPCとディスプレイが必要です。 |
| ウィンドウを画面の左側に配置する | `Win+Left` | 最前面のウィンドウをWindowsのスナップ機能で左側に配置します。既存の「左へ移動」とは異なる操作です。 |
| すべてのウィンドウを最小化する | `Win+M` | デスクトップ上のウィンドウをまとめて最小化します。 |
| 拡大鏡の倍率を下げる | `Win+Minus` | Windowsの拡大鏡を使用中に表示倍率を下げます。 |
| Windowsの通知と予定表を開く | `Win+N` | 対応するWindowsで、通知センターと予定表を開きます。 |
| 画面の自動回転をロック／解除する | `Win+O` | 画面の自動回転に対応する端末で、向きのロックを切り替えます。 |
| ディスプレイの表示モードを選ぶ | `Win+P` | 複製・拡張などを選ぶWindowsの投影メニューを開きます。メニューを開くだけでは表示モードを変更しません。 |
| Windowsのバージョン情報を開く | `Win+Pause` | Windowsの設定にあるシステムのバージョン情報を開きます。 |
| 絵文字パネルを開く（Win＋ピリオド） | `Win+Period` | 絵文字などを選ぶWindowsの入力パネルを開きます。 |
| 絵文字パネルを開く（Win＋セミコロン） | `Win+Semicolon` | 絵文字などを選ぶWindowsの入力パネルを開きます。記号のキー位置は送信先のキーボード配列に従います。 |
| 拡大鏡を起動／倍率を上げる | `Win+Plus` | Windowsの拡大鏡を開き、表示倍率を上げます。 |
| 画面全体のスクリーンショットを保存する | `Win+PrintScreen` | 画面全体を撮影し、Windowsのピクチャ内のスクリーンショット保存先へ画像を保存します。 |
| Windows検索を開く（Win＋Q） | `Win+Q` | Windowsの検索画面を開きます。 |
| ファイル名を指定して実行を開く | `Win+R` | 実行するファイル名やコマンドを入力するWindowsのダイアログを開きます。 |
| ウィンドウを画面の右側に配置する | `Win+Right` | 最前面のウィンドウをWindowsのスナップ機能で右側に配置します。既存の「右へ移動」とは異なる操作です。 |
| Windows検索を開く（Win＋S） | `Win+S` | Windowsの検索画面を開きます。 |
| ウィンドウのスナップ／最大化を解除する | `Win+Shift+Down` | 最前面のウィンドウがスナップ・最大化されている場合に、通常の表示へ戻します。 |
| UWPアプリを全画面表示にする | `Win+Shift+Enter` | 最前面がこの操作に対応するUWPアプリの場合に、全画面表示を切り替えます。 |
| ウィンドウを左のモニターへ移す | `Win+Shift+Left` | 複数のモニターを接続している場合に、最前面のウィンドウを左側のモニターへ移します。 |
| 最小化したウィンドウを元に戻す | `Win+Shift+M` | Windowsでまとめて最小化したウィンドウを復元します。 |
| 画面の範囲を選んで録画する | `Win+Shift+R` | 対応するSnipping Toolで録画範囲の選択を開始します。録画はWindows側の設定により動画フォルダーへ保存されます。 |
| ウィンドウを右のモニターへ移す | `Win+Shift+Right` | 複数のモニターを接続している場合に、最前面のウィンドウを右側のモニターへ移します。 |
| 画面の範囲を選んで撮影する | `Win+Shift+S` | Snipping Toolで撮影する範囲を選び、スクリーンショットを取得します。 |
| 前の入力言語／キーボード配列に切り替える | `Win+Shift+Space` | 登録済みの入力言語やキーボード配列を逆順に切り替えます。複数の入力方式がある場合に利用できます。 |
| ウィンドウを画面の上下いっぱいに広げる | `Win+Shift+Up` | Windowsの機能で、最前面のデスクトップウィンドウを縦方向に広げます。対応するウィンドウで利用できます。 |
| 通知を順番に切り替える | `Win+Shift+V` | Windowsの通知へ順番にフォーカスを移します。対象になる通知が必要です。 |
| 次の入力言語／キーボード配列に切り替える | `Win+Space` | 登録済みの入力言語やキーボード配列を順方向に切り替えます。複数の入力方式がある場合に利用できます。 |
| ウィンドウと仮想デスクトップの一覧を開く | `Win+Tab` | Windowsのタスクビューを開きます。2つの対象一覧にある同じキー操作を1コマンドにまとめています。 |
| Windowsのアクセシビリティ設定を開く | `Win+U` | 見やすさ・操作のしやすさを調整するWindowsの設定を開きます。 |
| ウィンドウを最大化する（Windows標準） | `Win+Up` | Windowsのキー操作で、最前面のウィンドウを最大化します。 |
| クリップボードの履歴を開く | `Win+V` | Windowsのクリップボード履歴を開きます。履歴が無効な場合はWindowsの案内が表示され、必要なら利用者が有効にできます。 |
| ウィジェットを開く | `Win+W` | Windowsのウィジェットが利用可能な環境で開きます。 |
| スタートのクイックリンクメニューを開く | `Win+X` | スタートボタンを右クリックしたときと同じWindowsのメニューを開きます。 |
| Mixed Realityとデスクトップの入力を切り替える | `Win+Y` | Windows Mixed Realityを利用できる旧環境向けです。Windows 11 24H2以降ではMixed Realityが削除されています。 |
| ウィンドウの配置レイアウトを選ぶ | `Win+Z` | 対応するWindowsとウィンドウで、スナップレイアウトの候補を開きます。 |
| 仮想デスクトップを追加する | `Win+Ctrl+D` | 新しい仮想デスクトップを作成して切り替えます。 |
| 右の仮想デスクトップに切り替える | `Win+Ctrl+Right` | 右隣の仮想デスクトップへ移ります。切り替え先がなければ何も起きません。 |
| 左の仮想デスクトップに切り替える | `Win+Ctrl+Left` | 左隣の仮想デスクトップへ移ります。切り替え先がなければ何も起きません。 |
| 現在の仮想デスクトップを閉じる | `Win+Ctrl+F4` | 現在の仮想デスクトップを閉じます。開いているアプリは終了せず、別の仮想デスクトップへ移ります。 |
