# Applet.WindowsTools.at365

ウィンドウの移動・高さ調整・最小化・最大化・復元・終了、Windows標準ショートカット、最前面アプリのフォルダー表示、消灯予約、Windowsのロック、無操作時の自動ロックを提供する AppDock 用 DLL Applet です。

## 動作環境

**Windows x64 / AppDock 0.62.3以降**が必要です。Windows標準のキー操作には「設定 → 操作の許可」の「Windowsへのキー・操作メッセージ送信」をONにしてください。既存のウィンドウ操作・消灯・ロックには、この入力許可は不要です。

## 導入・更新

1. AppDockをトレイの「終了」から完全終了します。
2. 配布物の `extension.json`、`Applet.WindowsTools.at365.dll`、`Applet.WindowsTools.at365.deps.json` を、AppDock.at365.exeの隣の `extensions/Applet.WindowsTools.at365/` に配置します。更新時も配布物一式をそろえて置き換えてください。
3. AppDockを起動し、「Applet」一覧で有効にします。操作やキーの割り当てはAppDockから行います。

利用するPCにはAppDockの動作環境が必要です。詳細は[AppDockの導入案内](../AppDock.at365/README.md)を参照してください。

## コマンドと設定

| コマンドID（`at365.windows-tools.` に続く部分） | 動作 |
| --- | --- |
| `open-folder` | 最前面アプリの実行ファイルがあるフォルダーをエクスプローラーで開く |
| `display-off` | 設定した秒数後にディスプレイを消灯。再実行すると予約し直す |
| `cancel-display-off` | 保留中の消灯予約を取り消す |
| `toggle-auto-lock` | 自動ロックの有効／無効を切り替えて保存 |
| `left` | 中央より右なら中央へ、次に左端へ、さらに左のモニターの右端へ移動 |
| `right` | 中央より左なら中央へ、次に右端へ、さらに右のモニターの左端へ移動 |
| `full-height` | 横位置と幅を基本的に保ち、タスクバーを除く作業領域の高さに合わせる |
| `center` | サイズを保ち、見えているウィンドウ枠を現在の作業領域の縦横中央へ移動 |
| `minimize` | ウィンドウへ通常の最小化要求を送信 |
| `maximize` | ウィンドウへ通常の最大化要求を送信 |
| `restore` | 最大化したウィンドウを通常のサイズに復元 |
| `close` | 通常の終了要求を送信。保存確認・終了のキャンセルは対象アプリが処理 |

| 設定 | 既定値 | 範囲・意味 |
| --- | --- | --- |
| ディスプレイが消灯するまでの秒数 | 5秒 | 1〜3600秒 |
| 無操作時の自動ロック | 無効 | マウス・キーボードの両方を監視 |
| 自動ロックまでの無操作時間 | 360分 | 1〜1440分 |

予約と無操作判定は1秒間隔で確認するため、実行は指定時刻から約1秒遅れることがあります。消灯時間の設定変更は次の予約から反映されます。自動ロックは有効化／監視時間の変更から数え直し、起動前の無操作だけを理由に直ちにロックしません。同じ無操作期間には1回だけロックを要求し、新しい入力があると再び監視します。

Appletの無効化・再起動・ホスト終了で消灯予約と監視を停止します。消灯予約は次の起動へ持ち越しません。PCロックはサインアウトやスリープではありません。

### Watch との対応

- Watch の「最前面アプリのフォルダーを開く」はプロセスの実行ファイルの場所を開く機能です。WindowsToolsも同じ動作です。エクスプローラーで閲覧しているフォルダーや、エディターで編集中の文書のフォルダー、プロセス内部の作業ディレクトリを取得する機能ではありません。
- Watch の消灯用ショートカットは1秒待機でした。WindowsToolsでは秒数を設定できます。
- Watch の自動ロックはマウスのみ・6時間固定でした。今回の「PCの操作がなかった場合」に合わせて、WindowsToolsは マウスとキーボードの無操作時間を使い、分単位で変更できます。

### Windows標準コマンドを使う

Windowsキーと仮想デスクトップのキー操作66件と「Windowsをロックする」を固定コマンドとして提供します。既存12件と合わせて79件を利用できます。[コマンド一覧と利用条件](docs/windows-shortcuts.md)を参照してください。共通のコマンド一覧とパレットに、送信キー・必要なアプリ・機器・Windowsの条件が表示され、説明の内容でも検索できます。

「Windowsをロックする」は直ちにWindowsへロックを要求し、自動ロックの設定は変更しません。対応しない機能の自動導入や設定変更は行いません。

### 独自のキー送信は本体のカスタムコマンドへ登録する

0.2.0で、このAppletのキー送信設定と`send.<ID>`コマンドを廃止しました。AppDock 0.62.0以降の「設定 → カスタムコマンド」で「キーを送信する」を選び、新しく登録してショートカット等を割り当ててください。[本体の利用案内](../AppDock.at365/README.md#カスタムコマンドの種類と説明)を参照してください。

旧設定の移行・旧コマンドIDの互換・割り当ての自動付替えは行いません。残った旧設定や割り当ては自動削除せず、旧コマンドは利用不可として扱います。固定12コマンドのIDは維持します。

ウィンドウ操作とフォルダー表示は、**実行時の最前面アプリ**が対象です。AppDockの画面から実行するとAppDock自身が対象になります。別のアプリを操作するときは、そのコマンドへグローバルショートカットを割り当ててください。ウィンドウ操作をマウスジェスチャーから呼び出した場合は、開始時の対象を操作します。対象が消えたり別プロセスへ変わった場合は操作しません。

### WindowMoverからの切り替え

WindowMoverの8コマンドを統合しています。WindowMover固有の設定項目はありません。コマンドIDは`at365.window-mover.<操作>`から`at365.windows-tools.<操作>`へ変わります。WindowsToolsを更新・有効にして、ショートカット・ジェスチャー・ピン留め・トレイ等の割り当て先を新しいコマンドへ変更し、旧WindowMoverを無効にしてください。割り当ての自動移行や旧Appletの削除は行いません。ウィンドウ操作と消灯・自動ロックの既存設定は維持します。

移動はWindowMoverの作業領域基準、負のモニター座標、DWMの不可視枠補正、上下端付近の吸着（上60px／下70px）を引き継ぎます。隣のモニターは現在の作業領域の幅だけ中心点をずらして選び、作業領域の上端または下端が一致する場合に移動します。端のモニターでは折り返しません。

移動・高さ調整ではマウスカーソル、フォーカス、Z順を変更しません。デスクトップ、タスクバー、タイトルなし、非表示、最小化中のウィンドウは除外します。中央移動は最大化中には何もせず、作業領域より大きいウィンドウも縮小しません。復元はWindowsの通常操作で、移動・高さ調整の取り消しや最小化した別ウィンドウの呼び戻しではありません。固定サイズ・全画面アプリや権限差により操作が適用されない場合があります。コマンド完了は要求の送信完了を表し、対象アプリによる処理完了を保証しません。

## 遅延開始・更新の確認

AppDock 0.5.0以降では「開始までの秒数」で遅延起動でき、「更新を確認」でGitHubの正式リリースを手動で確認できます。

## AppDockからの更新

AppDock 0.22.0以降では「設定 → バージョン情報・更新」の一括更新、またはこのAppletの個別更新ボタンを利用できます。配布元が`update.json`と`update.zip`を提供している場合に対応します。更新元は「インストール済みのApplet」の「更新元の設定」で変更し、保存してください。ローカルフォルダー・UNC・HTTP(S)・GitHub Releaseに対応し、「既定に戻す」も利用できます。

更新内容を確認して再起動すると配布ファイル一式を交換します。AppDock側の設定・有効状態・保存データは保持します。詳細は[AppDockの更新操作](../AppDock.at365/README.md#アップデート)を参照してください。

開発・ビルドについては[開発ガイド](DEVELOPMENT.md)を参照してください。

## Codexからの設定変更

「ディスプレイが消灯するまでの秒数」（1〜3600秒）を取得・変更できます。変更は次に消灯を予約するときの待ち時間へ反映され、設定変更だけで消灯しません。実行済みの予約時刻は変わりません。自動ロックの設定と消灯/ロックの実行コマンドは外部公開に含めません。

## 共通の設定画面

AppDockの「設定」またはApplet詳細の「設定」タブで、ディスプレイ・自動ロックのカードから編集できます。本体と同じテーマ・入力欄・自動保存を使い、起動待ちは末尾の共通カードにあります。固定コマンドのIDと、残す設定値は引き継ぎます。
